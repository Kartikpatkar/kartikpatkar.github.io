Privacy Policy

Last updated: August 13, 2026

This privacy policy outlines how personal information is collected, used, and safeguarded when visiting the portfolio website of Kartik Patkar (https://kartikpatkar.github.io).

1. Information Collection

This portfolio is a static website hosted via GitHub Pages. It does not actively track, capture, or store personal identifiable information, nor does it require user registration.

However, when utilizing the "Contact Form", standard email submission fields (Name, Email, and Message) are supplied. This form is processed through a standard email client workflow and is only transmitted when you explicitly send the email via your default mail client application. No data is stored in intermediate database servers by this site.

2. Cookies and Tracking

This site does not set tracking cookies or implement third-party analytics (like Google Analytics) to record individual user actions.

3. Third-Party Hosting

Hosting is provided by GitHub Inc. GitHub may collect server logs which include visitor IP addresses and basic browser metadata to secure and optimize web deliveries. For more details, consult the GitHub Privacy Statement.

4. Security

Standard HTTPS encryption is used for all asset transmissions. While reasonable security precautions are implemented, no transmission method over the internet is completely infallible.

5. Contact

For questions or requests concerning this privacy policy, reach out via email: kartikkp.assets@gmail.com.
